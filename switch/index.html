What it is

A free, MIT-licensed app (Go, with a tray panel on macOS, Windows and Linux, plus a window, a terminal UI and a CLI) that shows each AI coding agent installed on your machine and the model it is set to. Click a value, pick a model: Claude Code on Kimi, Codex on DeepSeek, Gemini CLI on GLM, per the README. To do it, it edits each agent's own config file (only the keys it needs) and runs a local gateway that translates between the OpenAI, Anthropic and Gemini formats. It also has profiles, quota failover between models and a usage view. The Claude, ChatGPT, Copilot, Gemini or Grok subscriptions you already have can act as providers too, as the README describes (the providers' terms on that were not checked). The maker lists sponsors first in the add-provider sheet, and the tool itself stays free and open source.

Setup

  1. Back up first. magpie edits your agents' config files, so copy ~/.claude/settings.json and ~/.codex/config.toml somewhere safe (on Windows: %USERPROFILE%\.claude\settings.json and %USERPROFILE%\.codex\config.toml). This is Axo's tip, not magpie's.

  2. Install. On macOS or Linux:

    curl -fsSL https://usemagpie.ai/install.sh | sh

  3. On Windows there is no one-line install: download magpie-windows-amd64.exe (about 47 MB, 44.9 MiB as Windows shows it; ARM: magpie-windows-arm64.exe, about 43 MB) from the maker's site or the releases page. The Windows build is not signed yet, so SmartScreen may ask before the first run.

    https://github.com/yetone/magpie-releases/releases/latest

  4. Add a provider with your own key (use a test key with a spend limit), in the app under Providers or in a terminal:

    magpie provider add deepseek sk-…

  5. Pick each agent's model: click it in the Agents tab, or in a terminal. Open a new agent session afterwards (for Codex, restart the Codex app too); sessions already open keep the model they started with.

    magpie claude deepseek/deepseek-v4-pro

  6. Keep magpie running (in the tray) while you use a model that goes through it. To undo it for one agent (it removes what it wrote and restores what it replaced):

    magpie claude default

Cheat sheet

  • Repository and README and the maker's start guide.
  • Useful if you run two or more coding agents and want to change models from one place, or you hit a quota in the afternoon. A routing group moves to the next account or model when one runs out, and the agent never sees the error, per the README (the reference adds: as long as no part of the reply has been sent).
  • Profiles snapshot every agent's setup under a name: magpie save work, then magpie use work.
  • See tokens, cost at list price and quota: magpie usage 7d and magpie quota.
  • Your agents' config files change and the keys you add live in ~/.config/magpie/providers.json, set to owner-only (0600) per the maker's docs; on Windows Axo did not check what that means. The file is not encrypted (only the magpie backup export is), and in portable mode it lives in a data folder next to the .exe. Back up and use keys with spend limits.
  • Windows: the .exe is about 47 MB and unsigned, and there are open issues, including Windows 11 Smart App Control blocking a new build (issue #894, still open). Since v0.1.1013 the updater test-launches a new build and rolls back if it is blocked, but one you double-click yourself is still refused; the maker says signing is under evaluation.
  • The tool is free, but each provider bills your own key. It is a young project (created 2026-09-23, version 0.1.x), so do not treat it as production-ready.
  • Telemetry: once a day magpie sends a random id, its version, your system and which agents, providers and models you use (magpie's own ids; a provider you add yourself shows as "custom"), plus counts for sponsor listings in the add sheet. No keys, URLs, accounts, prompts or usage. Turn it off in Settings → Privacy or with DO_NOT_TRACK=1.
  • Skip it if you use a single agent with its own login and never change models.
  • Not verified by Axo: how it runs on Windows, and whether it keeps its own backup copies of your agents' files.
