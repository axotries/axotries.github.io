What it is

A free, MIT-licensed skill for coding agents (Claude Code, Codex, Cursor, OpenCode and more). Ask a hard question and the agent writes a short Markdown draft; a CLI bundled in the skill turns it into a single HTML page: sequence diagrams, flow charts, ✓/✗ tables, timelines. A one-line question still gets a one-line answer, no page.

Setup

  1. You need Node.js 20 or newer. Nothing else to install: the CLI is bundled inside the skill.

  2. Easiest: paste this into your agent (Claude Code, Codex, Cursor, OpenCode…):

    Install Answer me with HTML: read https://raw.githubusercontent.com/QingYunA/answer-me-with-html/main/INSTALL.md and follow it.

  3. Claude Code plugin instead: run these inside Claude Code.

    /plugin marketplace add QingYunA/answer-me-with-html
    /plugin install answer-me-with-html@answer-me-with-html

  4. Any other agent, one command (the installer asks which agents to use):

    npx skills add QingYunA/answer-me-with-html

  5. Ask a question the way you always do, for example "Explain the TCP three-way handshake". Pages are saved in ~/.answer-me-with-html/pages/.

Cheat sheet

  • Repository and README.
  • Agent-friendly install guide.
  • Benchmark and the script to reproduce it: the 6.1x and 2.8x are the author's own medians (3 topics x 3 runs, Claude Sonnet 5.5, plain Claude Code setup), measured against asking the agent to write the HTML by hand (not against a plain-text answer), and not an independent test.
  • Heavy setups: the skill adds two short turns and every turn re-reads your context. With about 51,000 tokens of tools, rules and skills loaded, the author measured it about 20% more expensive. Speed-up held in every setup they tried.
  • Pages open in your browser after they are made. Turn that off with /answer-me-with-html config open off (plugin install: /answer-me-with-html:config open off).
  • Optional always-on mode adds a small page to every conclusion (about 90 tokens of reminder per turn). Pause it with /answer-me-with-html:config always off (plugin install) or /answer-me-with-html config always off (skills install).
  • Explainer videos (am video): narration uses ElevenLabs only if you set ELEVENLABS_API_KEY, otherwise the system voice. The MP4 export needs Chrome, ffmpeg and Node.js 22+.
