What it is

An open-source video framework where the video is a web page: you (or Claude) write HTML + animations, and it renders an MP4 frame by frame.

Setup

  1. Install Node 22+ and FFmpeg.

  2. Create a project and step into it

    npx hyperframes init my-video
    cd my-video

  3. Give your AI agent the skills (init already adds the core set; anywhere else, pick Core Skills)

    npx skills add heygen-com/hyperframes

  4. Preview and render

    npx hyperframes preview
    npx hyperframes render

  5. Optional local voice. Needs Python 3.10+, and the first run downloads 300 MB+.

    pip install kokoro-onnx soundfile
    npx hyperframes tts "Hello"

Cheat sheet

  • Use it for explainers, kinetic text, product demos, anything you can describe in code.
  • init pins its version: run npm run render and renders stay reproducible. Pixel-identical on any machine? npx hyperframes render --docker.
  • Use snapshot to check key frames before a full render.
