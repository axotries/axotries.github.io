What it is

A free, open-source roster of 282 specialist AI agents (engineering, design, marketing… even a "Whimsy Injector") that you install into your coding agent.

Setup

  1. Clone the repo

    git clone https://github.com/msitarzewski/agency-agents && cd agency-agents

  2. Install the agents into Claude Code (macOS or Linux; on Windows, use Git Bash or WSL)

    ./scripts/install.sh --tool claude-code

    Prints [OK] Claude Code: 282 agents -> …/.claude/agents

  3. Or use the desktop app (Option 1 in the README).

  4. In Claude Code, call an agent by name for a task in its specialty.

Cheat sheet

  • Use it when you want a role with rules, deliverables and metrics instead of a generic assistant.
  • Pick 3–5 agents you'll actually use: --agent frontend-developer,ui-designer installs just those. All 282 at once is a lot of noise.
  • Only 17 of 282 restrict their tools; the rest inherit yours.
